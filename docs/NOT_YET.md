# EH3D-DESIGN-EXPLORER: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Optimisation driven by artificial intelligence | Version 1 is deterministic; any proposal must be a reviewable difference | version 1 has been used |
| Searches with seeds (random or evolutionary) | The sweep is a plain grid by decision, so the same specification always gives the same alternatives | a grid is too big for a design |
| A single weighted score | A score hides the trade-off; the front is shown instead | a person asks for a ranking with weights they choose |
| A window to explore the front | The command line and the JSON files are enough to check the model first | the model of the study is accepted |
| A task kind for the server | The server has no kind of task for a study yet | the server accepts tasks from the engines |
